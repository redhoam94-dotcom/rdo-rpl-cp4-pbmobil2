Modul 1: Event Handling & Listeners

Merespon Interaksi Pengguna di Android

Aplikasi Android bersifat **Event-Driven**. Event terjadi saat pengguna menyentuh tombol, mengetik teks, atau menekan lama komponen UI. Pelajari cara memasang listener seperti `setOnClickListener`, `setOnLongClickListener`, `TextWatcher`, dan `setOnFocusChangeListener`.

Kode Listener Kotlin Utama 

// 1. OnClickListener (Klik Tombol)
binding.btnSubmit.setOnClickListener {
    Toast.makeText(this, "Tombol Diklik!", Toast.LENGTH_SHORT).show()
}

// 2. OnLongClickListener (Tekan Lama)
binding.btnSubmit.setOnLongClickListener {
    showOptionsDialog()
    true // return true agar event dikonsumsi
}

// 3. TextWatcher (Merespon Ketikan Teks Real-Time)
binding.etUsername.addTextChangedListener(object : TextWatcher {
    override function onTextChanged(s: CharSequence?, p1: Int, p2: Int, p3: Int) {
        binding.btnSubmit.isEnabled = (s?.length ?: 0) >= 3
    }
})

Intent Launcher Simulator

Pahami perbedaan antara Intent Eksplisit (pindah antar Activity internal) dan Intent Implisit (memanggil aplikasi sistem).

1. Explicit Intent

Target Class Didefinisikan Secara Pasti

Digunakan untuk berpindah antar halaman/Activity internal di dalam aplikasi Anda sendiri dengan menentukan nama kelas tujuan secara eksplisit.

val intent = Intent(this, DetailActivity::class.java)
startActivity(intent)

2. Implicit Intent Launchpad

Meminta Bantuan Aplikasi Sistem Lain

Tidak menentukan nama kelas, melainkan menentukan **Action** (seperti membuka URL, menelpon, atau membuka peta) agar Android memilihkan aplikasi yang sesuai.

Misi Perbaikan Kode Android

Temukan Bug pada Intent Data Passing!

Pengembang lupa menambahkan data ekstra atau salah mencocokkan kunci Key Intent. Pilih potongan kode yang **paling benar dan tanpa bug** di bawah ini.

Pilihan A (Bug Intent Key Mismatch): 
// MainActivity.kt:
intent.putExtra("USER_KEY", "Budi")

// DetailActivity.kt:
val name = intent.getStringExtra("NAME_KEY") // ❌ Key tidak cocok!
Pilihan B (Sintaks Tepat & Presisi): 
// MainActivity.kt:
val intent = Intent(this, DetailActivity::class.java).apply {
    putExtra("USER_KEY", "Budi")
}
startActivity(intent)

// DetailActivity.kt:
val name = intent.getStringExtra("USER_KEY") // ✅ Key cocok!
Pilihan C (Missing startActivity): 
// MainActivity.kt:
val intent = Intent(this, DetailActivity::class.java)
intent.putExtra("USER_KEY", "Budi")
// ❌ Lupa memanggil startActivity(intent)!
